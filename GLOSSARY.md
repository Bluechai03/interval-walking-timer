# Interval Walking Timer

A timer for Japanese interval walking: alternating fast and slow walking so the walker gets the benefit of hard effort with recovery in between.

## Structure of a walk

**Interval walking**:
The training method as a whole: repeated rounds of fast and slow walking, classically 3 minutes each for 5 rounds.
_Avoid_: Interval (for a single phase), IWT

**Plan**:
The configured sequence of phases the walker intends to do: how long each fast and slow phase lasts and how many rounds.
_Avoid_: Program, routine, workout

**Phase**:
One continuous stretch of walking at a single pace, either fast or slow.
_Avoid_: Mode, interval, segment, set

**Round**:
One fast phase followed by one slow phase.
_Avoid_: Set, rep, cycle

**Walk**:
One run through a plan, from Start until the last phase ends.
_Avoid_: Session, workout, exercise

## Rates

**Heart rate**:
The walker's heartbeats per minute, written in bpm. Each phase has a target heart-rate range.
_Avoid_: Pulse, bpm (on its own)

**Cadence**:
The walker's steps per minute, written as steps/min.
_Avoid_: bpm, pace, step rate

**Tempo**:
A song's beats per minute, used when matching music to a phase.
_Avoid_: bpm (on its own), speed
